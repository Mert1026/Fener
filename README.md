# Fener

AI model intelligence for understanding models, provider deployments, costs, evidence and workload fit.

**Every number needs a source.** Canonical models are not provider listings. Prices and benchmarks retain history; missing information is never filled with invented scores.

Built in validated vertical slices. See [architecture](docs/architecture.md), [data model](docs/data-model.md) and [development](docs/development.md).

Next.js / React / TypeScript, FastAPI / SQLAlchemy / Alembic, PostgreSQL, Python worker, pnpm and uv. Local development; no external deployment configured.
