# Contributing

Use small Conventional Commits. Run lint, types and relevant tests before committing. Commit lockfiles and migrations. Never commit secrets, private telemetry, backups or full raw snapshots.

Adapters separate fetching from normalization, include small labelled fixtures, document terms and validate input. Never merge identities using fuzzy strings. Every external displayed value needs provenance. Preserve observation history and benchmark version boundaries.

Pushing and public deployment require owner authorization. Preserve existing work; never rewrite history.
